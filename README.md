# MC服务器面板：先分清托管和自己装，新手也能开起服、管好服

搜「MC服务器面板」的人大致分两拨。一拨已经买好机器，卡在"面板到底装哪个"；另一拨还没花钱，想知道有没有那种登录网页点点鼠标就能开服、完全不用碰 SSH 的东西。这两拨人需要的信息不一样，所以先讲一个最容易被忽略的区别。

## 一、MC服务器面板其实分两种

**托管型**：服务商在后台替你装好了面板，你拿到一个网址、一个账号密码，登录进去就能开服。雨云游戏云里的「MCSM 面板」和「雨云面板」都属于这一类。

**自建型**：你租一台普通 VPS 或独立服务器，自己把面板装上去。开源方案里常见的三款是 MCSManager（MCSM）、Pterodactyl（翼龙）和 PufferPanel，也有服主直接拿 1Panel 或宝塔面板套 Docker 部署 MCSM。

差别不在功能多少，而在你愿意在"服务器本身"上花多少时间：

| 对比项 | 托管型面板服 | 自建面板 |
| --- | --- | --- |
| 上手成本 | 注册完基本就能开服 | 要自己处理 Java、防火墙、端口、进程守护 |
| 系统权限 | 受限，一般只能用面板给的那几种系统 | 完全自由 |
| 网络端口 | NAT 端口映射，数量有限 | 独立公网 IP 时端口基本随意 |
| 适合谁 | 几个人联机、第一次开服 | 多服务端并行、长期运营、机器上还要跑别的东西 |

如果只是和朋友玩，托管型面板服足够。想同时跑三四个不同版本的服务端，顺便再挂个网站，那自建更省事。

## 二、面板能替你干什么，干不了什么

先把预期摆正：**面板不会让你的服务器变快。**

它解决的是操作层面的麻烦事：

- 一键安装和切换服务端核心（Paper、Forge、Fabric、整合包都可以）
- 网页控制台，不用守着命令行窗口看日志
- 文件管理，上传服务端 jar、改配置文件、打包备份
- 多实例管理，一个面板管好几台服务器
- 权限分配，给朋友开个只能看控制台的子账号，不用把 SSH 账号交出去

但 TPS 掉到 15 的时候，换面板一点用都没有。卡顿要么是 CPU 单核性能不够，要么是内存分配不合理，要么是视距和实体数量堆太多。这是新手最容易搞错的地方——折腾半天面板，问题根本不在面板上。

面板也不负责网络。NAT 机型要手动加端口映射：MCSM 自己需要 23333（Web）和 24444（守护进程）两个端口，Minecraft 默认用 25565，开基岩版还得放行 UDP 19132。漏掉任何一个，游戏里都会连不上。

## 三、挑面板前先看四个硬指标

1. **CPU 单核性能。** MC 的主线程基本是单核在跑。高版本更吃资源：1.18+ 的消耗大约是 1.16+ 的两倍，1.12 更是三倍左右。同价位下，高频 CPU 比多核实用。
2. **内存。** 服务端最低 2GB 起步，两人以上建议 4GB，带模组整合包要继续往上加。系统本身也占内存，别把物理内存全塞给 `-Xmx`。
3. **计费模式。** 每天在线时间长的选固定计费，只在周末晚上玩几小时的，动态计费更划算。
4. **Java 版本能不能对上。** 1.21.x 的服务端要 JDK 21+，1.20.x 要 JDK 17+，1.16.x 及更早用 JDK 8+。这也是为什么很多自建教程推荐用 Docker 跑服务端，切版本不用重装整个系统。

## 六、从注册到进服的完整流程

1. **注册并认证。** 通过下方链接注册，在注册页填优惠码（如果页面有这个输入框），完成后到「账户设置」里绑定微信，可以领一张新用户 5 折优惠券，绑定后消费还有积分返现。
2. **选产品形式。** 想零成本先试，走积分商城兑换免费面板服；想长期开，直接买 MCSM 面板或雨云面板机型。开 1.20+ 的高版本服，建议 4 核 8G 起。
3. **选计费和网络。** 经常玩的选固定计费，周末党选动态计费。公网 IP 选 NAT 就够，15 个端口映射对 MC 服绰绰有余。
4. **重装 / 切换游戏。** 在游戏云管理页里选 Minecraft Java 版和你要的服务端核心，系统会自动装好。
5. **进 MCSM 控制台调启动脚本。** 上传自己的服务端 jar，把启动脚本里的文件名替换掉。基础写法是 `java -Xms4G -Xmx4G -jar 服务端名.jar`，`-Xmx` 记得比物理内存小一点，留出系统占用，另外建议配一块 Swap。
6. **第一次启动一定要改 eula。** 在文件管理里找到 `eula.txt`，把 `false` 改成 `true`，再重启。
7. **离线玩家要关正版验证。** 在 `server.properties` 里把 `online-mode=true` 改成 `false`，否则只有正版账号能进。
8. **加端口映射。** 到「信息与监控」里建规则，MCSM 的 23333 / 24444 和 MC 的 25565 都映射出去，复制生成的外网地址，填进游戏里的「添加服务器」。

下面这套流程走完，控制台打出 `Done` 就说明服务端起来了。第一次启动如果直接卡住，八成是 Java 版本不匹配，或者 `eula` 没改。

## 七、常见问题

**免费面板服能开多大？** 配置不高，适合几个人联机。积分可以反复续期，但机器本身撑不住大型公开服。

**面板服能装模组吗？** 能，但要换服务端核心。原版和 Paper 只支持插件，模组要用 Forge、Fabric 或 NeoForge，也可以在「重装 / 切换游戏」里直接换成对应核心。

**动态计费会突然变贵吗？** 它的逻辑是低价月租加上按 CPU 使用率结算的"电量"，基准值是 20%，低于这个值的时段不额外计费。每天只玩一两小时，通常比固定计费便宜；一直满载跑，反而固定计费更划算。另外可以手动关掉"用余额结算电费"，避免电量超了自动扣钱。

**存档怎么备份？** 面板自带备份功能，也可以直接在文件管理里把 `world` 文件夹下载到本地。定时备份比什么都重要，插件冲突或者误删一次就够心疼的。

**试错成本高吗？** 雨云支持 7 天内无理由退订，云服务器和游戏云产品都可以 1 元试用一天（每款限 1 次，贵一点的机型试用价会高一些）。买之前先试一天是成本最低的做法。

## 八、什么时候该加钱

判断标准很简单：降过视距、减过插件、确认内存分配合理之后，TPS 还在 18 以下晃，那就是硬件到顶了。

这时候优先加的不是核数，而是换更高主频的 CPU 机型，因为 MC 主线程吃的是单核性能。玩家到十来个人、开始跑整合包的时候，4 核 8G 就该往 6 核 12G 走了。项目里说"用积分续期就能一直白嫖"，那是小服玩法；真要长期运营，付费机型的稳定性和备份能力才是关键。
